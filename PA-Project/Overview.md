# Personal AI System — Project Overview

## Vision
A fully autonomous personal AI system that:
- Plans Arjun's day intelligently around shifts
- Learns and remembers everything about him
- Runs specialist sub-agents for different life areas
- Is accessible from phone anywhere in the world
- Works across Claude, ChatGPT, and any AI
- Costs nothing or near nothing to run

## Architecture
- Frontend: Telegram bot (phone access anywhere)
- Backend: Groq free tier (cloud AI, swappable models)
- Memory: Obsidian + GitHub (this repo — universal, editable by any AI)
- Calendar: Google Calendar API
- Language: Python

## Why This Stack
- Telegram: free, works on any phone, no app to build
- Groq: free tier, fast, hosts best open source reasoning models, swap model with one line
- Obsidian + GitHub: plain text files, any AI can read/write, you own everything, works forever
- Python: most AI/automation libraries available, beginner friendly

## Key Principles
- Device independent — works if Mac is replaced
- Model independent — swap AI models as better ones release
- AI independent — Claude, ChatGPT, any AI can use same memory
- Free or near-free to run
- Arjun can read and edit everything himself in Obsidian
